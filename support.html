Pour un problème, indiquez si possible le modèle de l’appareil et la version du jeu, écrite en bas de l’espace parents.

Questions fréquentes

  • Ouvrir l’espace parents : sur la carte, gardez le doigt 2 secondes sur la roue dentée en haut à droite, puis écrivez le résultat du calcul demandé.
  • Changer de classe : dans l’espace parents, « Classe de l’enfant ». Chaque classe garde sa propre progression.
  • Limiter le temps de jeu : dans l’espace parents, « Réglages », choisissez la durée des sessions.
  • Couper le son, la musique ou la voix : dans l’espace parents, « Réglages ».
  • Retrouver la progression sur un autre appareil : dans l’espace parents, « Copier le code de sauvegarde », puis « Restaurer depuis un code » sur l’autre appareil.
  • Tout effacer : dans l’espace parents, « Tout effacer… ». Désinstaller l’application efface aussi ses données.
  • Compte, achats, publicité : il n’y en a pas. Le jeu ne collecte aucune donnée.
