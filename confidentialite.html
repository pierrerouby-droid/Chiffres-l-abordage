Politique de confidentialité

Moussaillon

Ce jeu est fait pour les enfants de 6 à 11 ans. Il ne collecte aucune donnée personnelle et n’envoie rien à un serveur. Cette page explique ce qui est enregistré, où, et comment l’effacer.

En résumé

  • Aucune donnée n’est collectée par l’éditeur du jeu ni par un tiers.
  • Pas de compte, pas de publicité, pas d’achat, pas de statistiques d’utilisation, pas de traceur, pas de cookie.
  • La progression de l’enfant reste sur l’appareil.

Ce qui est enregistré sur l’appareil

Pour que l’enfant retrouve sa partie, le jeu garde dans la mémoire de l’appareil (stockage local de l’application) :

  • le prénom ou le surnom choisi à la première ouverture, et la classe (du CP au CM2), pour chaque enfant ajouté sur l’appareil ;
  • la progression : niveaux, étoiles, réussite par notion, dernières erreurs, doublons gagnés, objets achetés dans le jeu avec ces doublons ;
  • les minutes jouées par jour, pour le tableau de bord des parents ;
  • les réglages : son, musique, voix, durée des sessions.

Ces informations ne quittent jamais l’appareil. L’éditeur du jeu n’y a pas accès.

Ce qui peut sortir de l’appareil, seulement si un parent le décide

  • Votre avis : dans l’espace parents, le bouton « Donner mon avis » prépare un texte que vous envoyez vous-même avec l’application de votre choix (Messages, e-mail…). Il contient vos réponses et, si vous laissez la case cochée, un résumé de jeu : niveaux et réussite par notion, minutes jouées, modèle de téléphone. Il ne contient pas le prénom de l’enfant. Rien n’est envoyé sans votre geste.
  • Le code de sauvegarde : il est créé sur l’appareil et copié par vous, pour retrouver la progression sur un autre appareil. Il n’est envoyé nulle part.

Hébergement du jeu

Les fichiers du jeu (pages, images, sons) sont hébergés par GitHub Pages. Quand un appareil les télécharge, GitHub enregistre son adresse IP pour des raisons de sécurité, comme pour tout site qu’il héberge. L’éditeur du jeu n’a pas accès à ces données. Pour en savoir plus : la déclaration de confidentialité de GitHub, sur docs.github.com.

La version pour iPhone et iPad contient les fichiers du jeu : elle n’a pas besoin de les télécharger.

Effacer les données

  • Dans l’espace parents, « Tout effacer… » supprime la progression et les réglages.
  • Désinstaller l’application supprime aussi toutes ses données de l’appareil.

Enfants

Le jeu ne demande aux enfants aucune information de contact et ne permet pas de discuter avec d’autres personnes. L’espace parents, d’où partent l’avis et la sauvegarde, est protégé par une question réservée aux adultes.

Contact

Pour toute question sur cette politique, écrivez au développeur : pierrerouby@gmail.com.

Si cette politique change, la nouvelle version sera publiée sur cette page, avec sa date.
